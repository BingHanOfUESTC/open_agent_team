# Presentation Storyline Design

Use this skill to convert material and research into a coherent deck structure.

## Core Model

Every deck must answer:

```text
Who is the audience?
What decision or understanding should change?
What is the one controlling message?
What evidence order makes that message credible?
What action should happen after the deck?
```

## Common Structures

```text
Decision deck:
  Context -> Problem -> Options -> Evidence -> Recommendation -> Next steps

Strategy deck:
  Current state -> Market/constraints -> Opportunity -> Strategic choices -> Roadmap

Research deck:
  Question -> Method -> Findings -> Interpretation -> Implications

Sales deck:
  Customer pain -> Insight -> Solution -> Proof -> Offer -> Next step

Training deck:
  Why it matters -> Concept -> Example -> Practice -> Checklist
```

## Slide List Fields

```text
slide_id
section
purpose
headline_draft
evidence_needed
recommended_visual
transition_from_previous
```

## Rules

```text
One slide, one job.
Use headlines as claims, not labels.
Create chapter transitions.
Put dense explanation in speaker notes, not the slide body.
Cut slides that do not advance the audience.
```
