# Paper Writing Team

`paper_writing_team` turns long research materials into a complete academic paper draft, revision plan, and optional rebuttal package.

Use `@team_lead_agent` as the entry point.

## Workflow

```text
Boss brief -> long-material evidence cards -> contribution framing -> outline -> section drafts -> consistency review -> revision -> delivery
```

## Handles Long Inputs

Long papers, experiment logs, tables, reviewer comments and notes must be chunked into evidence cards before synthesis. Do not paste full source material into one prompt.

## Default Delivery

```text
delivery/manuscript.md
delivery/abstract.md
delivery/related_work.md
delivery/rebuttal_response.md
materials/evidence_cards.md
reviews/manuscript_review.md
```
