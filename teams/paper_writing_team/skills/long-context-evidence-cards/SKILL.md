# Long Context Evidence Cards

Use for papers, notes, logs, tables and reviewer comments that exceed context limits.

## Process

```text
Split by source -> chunk by section/table/comment -> summarize into cards -> keep location -> synthesize only from cards.
```

## Card Schema

```text
id
source
location
claim_or_result
method_detail
numbers
limitations
usable_section
confidence
```

Never synthesize from memory when a card is missing.
