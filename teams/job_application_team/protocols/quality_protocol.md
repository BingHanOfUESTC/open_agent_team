# Job Application Quality Protocol

```text
Do not invent employers, degrees, titles, dates, metrics, tools or achievements.
Tailor to the JD using evidence from the candidate profile.
Prefer quantified impact only when supported.
Keep ATS readability high: simple headings, clear bullets, standard section names.
Use STAR evidence for interviews.
```

## Gates

```text
Truthfulness < 9.5: revise.
JD alignment < 8.5: revise.
Resume scanability < 8.5: revise.
Achievement specificity < 8.0: revise.
Interview answer evidence < 8.5: revise.
```
