# Job Application Team

`job_application_team` creates tailored resumes, cover letters, outreach messages and interview prep from a candidate profile and target job descriptions.

Use `@team_lead_agent` as the entry point.

## Long Input Handling

Long resumes, portfolios, project docs, transcripts and many job descriptions must be chunked into profile/JD evidence cards before tailoring.

## Default Delivery

```text
delivery/resume.md
delivery/cover_letter.md
delivery/linkedin_outreach.md
delivery/interview_prep.md
delivery/application_trace.md
```
