# Software Architect Team

`software_architect_team` converts product or engineering requirements into architecture decisions, APIs, data models, risks and implementation roadmap.

Use `@team_lead_agent` as the entry point.

## Default Delivery

```text
delivery/architecture_proposal.md
delivery/adrs.md
delivery/api_design.md
delivery/data_model.md
delivery/implementation_roadmap.md
delivery/risk_register.md
```
