# Course Creator Team

`course_creator_team` turns a topic, source materials and learner profile into a complete course package.

Use `@team_lead_agent` as the entry point.

## Long Input Handling

Books, papers, notes, manuals, transcripts and slide decks must be chunked into learning objective evidence cards before curriculum design.

## Default Delivery

```text
delivery/course_syllabus.md
delivery/lesson_plans.md
delivery/assignments.md
delivery/quiz_bank.md
delivery/teacher_script.md
```
