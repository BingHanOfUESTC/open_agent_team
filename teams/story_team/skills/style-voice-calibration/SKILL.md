# Style Voice Calibration

语言风格不是“更文学一点”。风格是稳定的选择：叙述距离、句长、词汇、观察对象、幽默方式、沉默方式和情绪处理方式。

---

# 1. 写作前的风格锁定

每篇短篇至少锁定：

```text
叙述距离：冷近 / 热近 / 克制远景 / 第一人称偏见
句子节奏：短促 / 累积 / 断裂 / 平稳
词汇质地：日常 / 职业化 / 方言感 / 诗性但克制
感官优先级：声音 / 气味 / 触感 / 物件 / 身体反应
情绪策略：压住 / 误导 / 自嘲 / 反讽 / 延迟爆发
禁用腔调：鸡汤、网文爽感、散文腔、AI 总结腔
```

---

# 2. 声音区分

角色声音来自：

```text
他关心什么
他回避什么
他句子长短
他是否正面回答问题
他用哪些职业词、生活词、口头习惯
他在紧张时变啰嗦、变冷、变刻薄还是沉默
```

不能只靠口癖区分人物。

---

# 3. 去 AI 平滑

AI 默认会：

```text
解释情绪
补齐因果
把冲突说圆
让每个人都说正确的话
用对称句制造假文学感
在段尾总结意义
```

返修时要反向处理：

```text
删掉解释，让动作承压
留下恰当的不完整
让人物说偏、说错、说半句
让段落停在具体物件或行为上
```

---

# 4. 风格自检

```text
任意一段去掉角色名，是否还能感觉到 POV？
任意一句漂亮句子，是否承担情节或人物功能？
每个角色的对话是否可以互换？
段尾是否总在总结？
```
