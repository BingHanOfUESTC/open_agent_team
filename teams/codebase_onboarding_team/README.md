# Codebase Onboarding Team

`codebase_onboarding_team` helps developers understand an unfamiliar repository.

Use `@team_lead_agent` as the entry point.

## Long Repo Handling

Do not dump the whole repository into context. Build a repo inventory, identify entrypoints, sample key files, then create architecture and onboarding evidence cards.

## Default Delivery

```text
delivery/onboarding_guide.md
delivery/architecture_map.md
delivery/key_files.md
delivery/developer_quickstart.md
delivery/risk_notes.md
```
