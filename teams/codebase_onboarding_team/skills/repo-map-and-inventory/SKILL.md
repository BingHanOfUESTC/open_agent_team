# Repo Map And Inventory

Use before reading a large repository.

## Process

```text
List top-level files and directories.
Identify language/framework/package manifests.
Find entrypoints, configs, tests and docs.
Exclude vendor, generated, build and cache directories unless relevant.
Create evidence cards for key files.
```

## Output

```text
repo tree summary
technology stack
entrypoints
test/build commands
key files
unknowns
```
