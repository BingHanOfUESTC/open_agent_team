# Codebase Onboarding Quality Protocol

```text
Never claim behavior without file evidence.
Use repo inventory before reading individual files.
Prefer entrypoints, configs, tests, package manifests, routing files and core modules.
Represent uncertainty explicitly.
Do not summarize generated/vendor/dependency folders unless relevant.
```

## Gates

```text
Architecture accuracy < 8.5: revise.
Evidence traceability < 9.0: revise.
Developer usefulness < 8.5: revise.
Setup clarity < 8.5: revise.
Risk coverage < 8.0: revise.
```
