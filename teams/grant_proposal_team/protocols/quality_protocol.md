# Grant Proposal Quality Protocol

```text
Never invent eligibility, preliminary results, collaborators, facilities or budget facts.
Map every major section to the funding call.
Separate required content from strategic suggestions.
Track page limits, formatting constraints, required attachments and review criteria.
Use evidence cards for long calls and PI material.
```

## Gates

```text
Guideline compliance < 9.0: revise.
Significance/innovation/approach clarity < 8.5: revise.
Feasibility evidence < 8.5: revise.
Budget consistency < 9.0: revise.
Reviewer-perspective quality < 8.5: revise.
```
