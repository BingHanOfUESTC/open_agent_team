# Grant Proposal Team

`grant_proposal_team` converts a funding call, PI materials, prior work, and project idea into a compliant grant proposal package.

Use `@team_lead_agent` as the entry point.

## Long Input Handling

Funding guidelines, CVs, prior papers, budgets and institutional templates must be chunked into requirement/evidence cards before writing.

## Default Delivery

```text
delivery/proposal.md
delivery/specific_aims.md
delivery/project_summary.md
delivery/budget_justification.md
delivery/compliance_checklist.md
```
