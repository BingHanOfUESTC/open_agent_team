# Bug Triage Team

`bug_triage_team` turns error reports, logs, stack traces, issues and code context into reproduction plans, root-cause hypotheses, fix candidates and verification plans.

Use `@team_lead_agent` as the entry point.

## Default Delivery

```text
delivery/triage_report.md
delivery/reproduction_plan.md
delivery/root_cause_hypotheses.md
delivery/fix_options.md
delivery/verification_plan.md
```
